# Ayoi蘭嶼健康行動—護理健康到您家APP 原型

這是一個可直接開啟的雙介面 Web App 原型，用於討論蘭嶼全齡分齡健檢、家訪問卷、檢驗值收集、個資同意與家庭健康設計模組。

## 啟動

```bash
python3 -m http.server 4173 --directory lanyu-health-app
```

開啟：

```text
http://localhost:4173
```

GitHub Pages：

```text
https://qpig0218.github.io/lanyu-health-app/
```

## 介面

- 醫療/護理端：家戶名冊、家戶總覽、家訪問卷、分齡健檢、檢驗值輸入、分流與家庭健康設計模組。
- 民眾端：家庭健康卡、問卷步驟、健檢預約、結果查看與補資料提醒。

## 已納入資料模組

- 個資與同意：姓名、身分證/替代識別碼、生日、性別、村別地址、聯絡人、同意書版本、撤回紀錄。
- 家戶資料：家戶編號、成員 roster、照顧者、交通可近性、居住安全、家庭健康目標。
- 全齡健檢：0 歲至 85 歲以上分齡方案，包含兒童、學生、成人、55 歲以上原住民、高齡功能與癌篩個別化邏輯。
- 檢驗值：檢查代碼、項目、數值、單位、參考範圍、異常旗標。
- 家訪問卷：家戶、個人健康、醫療利用、預防保健、生活暴露、年齡別加強模組。
- 分流：P0-P9 個人服務標籤與 H1-H10 家庭健康設計模組。

## 後續可擴充

- 接後端資料庫與身分權限 RBAC。
- 支援離線家訪草稿與回網同步。
- 匯入台東馬偕健檢結果 CSV/Excel。
- 產出衛生所、照護司、部桃/東馬不同權限儀表板。
- 將民眾端包成 PWA 或行動 APP。
